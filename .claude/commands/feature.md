---
description: Plan and build a feature slice
---

Use the `feature-slice` skill. Before writing code, tell me in five lines:

- what changes in the database
- what goes in `packages/core` (schemas, strings, logic)
- which queries and actions are needed
- which screens, and which parts of them have to be client components
- what this will need when `apps/mobile` exists

Then build it in that order.
